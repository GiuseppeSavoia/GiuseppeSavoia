### 🎯 How I like to build

- **Test what matters**: offline test suites with fake data sources, so every project runs `pytest` / `npm test` without the network.
- **No magic numbers**: parameters in config, decisions in a log, research designed to *falsify* ideas rather than sell them.
- **Ship it**: from scraper to UI to a double-clickable app.
